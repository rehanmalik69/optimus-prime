Optimus Prime - Your Personal Voice Assistant

Project Overview:
Optimus Prime is a Python-based voice assistant designed to perform various tasks on voice commands. With features like Wikipedia search, opening websites, playing music, and more, it simplifies routine operations through natural speech.

Features:
Wikipedia Integration: Search Wikipedia and receive summarized results.
Web Browsing: Open popular websites like YouTube and Google on command.
Music Playback: Play your favorite songs from a pre-defined directory.
Time Check: Get the current time with a simple voice command.
Application Launch: Open applications like Visual Studio Code and WhatsApp.
Custom Greetings: Personalized greetings based on the time of day.
Voice Recognition: Uses speech recognition for hands-free operation.
Customizable Commands: Easily extend or modify the assistant's functionality.

Installation:
Prerequisites
Python 3.6+ installed on your system.
